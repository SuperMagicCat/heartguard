心援计划 · 怎么发给别人玩

一、打包
把整个项目文件夹压缩成 zip（要能看到里面同时有「启动游戏.bat」「index.html」「game.js」「image」「audio」「content」「godot-heart」「fonts」「admin」）。
不要只发一个 bat，也不要只发 index.html。

二、对方怎么玩（Windows）
1. 完整解压到一个文件夹。
2. 双击「启动游戏.bat」，弹出的黑窗口先不要关。
3. 浏览器会打开封面。点「开始」，先走问诊问答，答完并起名字后才进入主页。
4. 关掉黑窗口 = 关掉游戏。

不要直接双击 index.html，那样资源会加载失败。
电脑上有 Python 3 更稳（安装时勾选 Add python.exe to PATH）。没有的话，脚本会尝试用系统自带方式启动。

手机：电脑启动后，同一 WiFi 下可试黑窗口里打印的「同网手机」地址（需已安装 Python 并成功启动）。
